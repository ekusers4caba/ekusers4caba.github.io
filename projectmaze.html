About the project

Project Maze is a survival horror game set inside a procedurally generated, backrooms-inspired arena. Endless, near-identical rooms and corridors stretch out in every direction, and the layout is different every run, so there is never a route to memorise.

Something else is in there with you. A frightening entity stalks the player through the maze and will chase them down. The goal is simple: stay alive. Time is the measure of everything, so every extra second you survive counts.

This project was created for a University course on game development. To showcase our skills and understanding of game design principles.

Key features

  • Procedurally generated backrooms-style arena, new layout every run
  • A relentless entity that chases the player through the maze
  • Survival-time scoring: the longer you last, the better you did

What I learned

Procedural generation

How procedural generation works and how to ensure variety while maintaining playability.

Enemy AI and pathfinding

How to implement AI behavior for an enemy that can effectively chase the player while maintaining a sense of threat and fairness.

Building tension

How to create and maintain tension in a horror game through pacing, lighting, and sound design.
